rvifm 帮助（vim 风格文件管理器）
参考 vifm 交互范式，非 fork、非行为级兼容。

== 导航 ==
  j / k           光标下移/上移（首尾环绕；首行 k 上到 ".." 行）
  ↑ / ↓           同 k / j（←→ 同 h/l；双栏一致）
  l / Enter       进入目录/归档；普通文件用系统默认程序打开
  h               返回上级目录（归档根返回归档所在物理目录）
  gg              跳到列表顶部（".." 行）
  G               跳到列表末项
  Ctrl-u / Ctrl-d 半页上翻/下翻
  ..              列表顶部固定条目：l/Enter 返回上级；根目录隐藏

== 搜索与过滤 ==
  /{词}           搜索（实时跳转 + 匹配子串高亮 + 计数 i/N；作用于焦点 pane）
  n / N           下一个/上一个匹配
  ={glob}         过滤（如 =*.txt；Esc 清除）
  f / F {字符}    按文件名首字符快速定位（; 同向重复，, 反向）
  :find {模式}    递归文件名查找（结果为虚拟目录，全路径显示；上限 1 万）
                  过滤器：--size [+-=]N[bkmg] --mtime [+-]N(天)
                  --type f|d --depth N；命名搜索 save/load <名>（仅本会话）
  :grep {模式}    内容搜索（regex；条目 = 路径:行号: 内容；上限 1 万）
  o               跳转选择器（frecency 合一视角）
  :j / :J         仅目录 / 仅文件的跳转选择器
  :recent         近期视角（全部条目按最后访问时间倒序，含会话内跳转）
  '{字符}         marks/bookmark 跳转（跳到该 keyword 的最高排名条目：
                  目录 cd、文件父目录定位光标；多字符 keyword 在
                  o/:j/:J 搜索中享有高优先级匹配）

== marks 与书签 ==
  m{字符}         标记当前条目（字母/数字；".." 行 = 当前目录）写入
                  frecency 持久化存储（与书签共用数据）
  :bmark <tag> [tag2...]
                  为当前目录设置书签 tag（与 marks 共用数据）
  :bmarks [tag...]  列出书签（无参 = 全部）
  :bmgo <tag> [tag2...]   按 tag 跳转（首个命中的最高排名条目）
  :delbmarks [tag...] / :delbmarks! <path...>
                  清除书签（保留累积分数；! 按路径清除）

== 选择、标记与批量 ==
  v               可视选择（j/k 扩选，Esc 退出）
  V               行可视模式（与 v 互斥；d/y/x 对选中区域执行）
  t               标记/取消标记当前条目（tag）
  :select {glob}  按 pattern 批量标记（无参=当前条目）
  :unselect       同上取消（无参=清空全部）
  :tag copy|move|delete <目录>   对标记集合执行批量操作（复制/移动后台执行）

== 文件操作 ==
  yy              复制到 yank 缓冲区（可视选择/标记优先，count 前缀支持 Nyy）
  y / yn / yf / yc
                  复制序列（y=条目名, yn=名称, yf=全路径, yc=内容；OSC52 优先）
  p / P           粘贴：p=复制到当前目录，P=移动到当前目录
  dd              删除（应用内暂存，u 可恢复）
  DD              永久删除（不可恢复，强提示）
  u               撤销上一次操作（逆序，跨 tab）
  cw              批量重命名（$EDITOR 编辑名单）
  :rename 新名    重命名当前条目
  :rename s/<pat>/<repl>/[i] | prefix=/suffix=/seq=<start>,<step>,<width>
                  结构化批量重命名（结果视图预览，y=应用整批 / Esc=取消）
  :copy / :move <目录>
  :link <dest>    创建符号链接（dest 为已存在目录时在其内批量建链；u 可逆）
  :mkdir / :touch <名>   （:mkdir 后光标定位新目录）
  :mk <名>        创建并进入新目录
  :cd <目录>
  :file           显示当前条目详情（路径/大小/权限/修改时间/类型）
  :keyword <chars>  设置当前目录书签 keyword（`-` 清除；' 直达的锚点）
  s               进入 shell（$SHELL；退出返回，光标与滚动不变）
  :!<cmd>         外部命令（$TMUX/$STY 下新窗口执行；[ui] terminal_in_new_window 可配）

== 多标签 ==
  :tabnew / :tabclose
  gt / gT / {N}gt 切换标签
  :tabmove {N}    调整标签顺序
  :tabname <名>   命名当前标签（无参清除；仅本会话）；标签溢出自动滚动（‹ ›）
  布局选项        [ui] layout = single|dual|preview-right|preview-bottom
                  （缺省 dual；view 模式查看器占位随布局）

== 视图 ==
  Tab             切换左右 pane 焦点（双栏均可导航）
  : / gt / gT     双栏一致：右 pane 下 : 进入命令模式（作用于焦点 pane），
                  gt/gT/{N}gt 切标签，gg 跳右栏顶部
  w               右 pane 在目录列表与预览间切换（预览小图原尺寸居中、大图按宽适配）
  w（二进制文件） hex 完整视图（16 字节/行：偏移 + ASCII 侧栏；分块读取；
                  :goto <0x偏移|十进制> 跳转；无编辑）
  [ / ]（PDF）     查看器 PDF 翻页（任意页按需渲染；需 pdf_image_pages>0
                  或外部工具，文本层足够且无 prefer 时回退文本）
  CSV/TSV 预览    表格对齐（列宽=最长单元格；naive 分隔，引号内分隔符不解析）
  图片信息        预览信息面板含容器尺寸/格式（PNG/JPEG/GIF/BMP 头解析）
  S               排序对话框（字母直接应用 / 空格切换方向 / 回车确认）
  :sort 字段,...  多字段排序（name/natural/mtime/size/ext，逗号分隔 + asc/desc）
  :tree           树视图（只读，depth 可选；再执行恢复平铺）
  :archive [格式] <名> [checksum=md5|sha256|none]
                  归档创建（内建 zip/tar/tar.gz/7z；rar/cab/lzh/tar.* 走外部 CLI；
                  tags 优先，空=光标条目；无参打开对话框；校验默认 md5）
  :chmod [-R] <mode>  批量属性（八进制/符号 u+x；POSIX only）
  :extract [目录]  归档解压到磁盘（zip-slip 防护；u 可撤销）
  :sync [l2r|r2l] [--apply] [--delete]
                  目录同步（dry-run 缺省；--apply 执行）
  :du             磁盘占用（总计 + top-5）
  :dup            查重（SHA-256 精确比对）
  :checksum       生成 md5 sidecar（md5sum -c 兼容）
  :trash [clear|purge --before=<天数>]
                  暂存区菜单/清空/按时间清理（清除不可恢复）
  :compare [byname|bycontents]
                  左右 pane 目录对比（缺省按名+大小；bycontents 用 SHA-256
                  内容判定，单文件 64MB 上限、超限按不同计；只读）
  dp / do         对比结果视图同步：dp 取回另一侧条目到当前侧（仅 >）；
                  do 删除当前侧多出条目（仅 <，暂存可恢复）；u 可逆
  :view           同 w
  Ctrl-G          文件详情对话框
  :jobs           后台作业列表（j/k 选择、x 取消、p 暂停/恢复、Enter 详情、Esc 关闭）
  （跨 VFS 粘贴）  传输连接类失败自动重连一次；失败现场 .part 保留（重试粘贴可续传/诊断）
  :trash          暂存区菜单（恢复误删文件）
  :theme [名]     切换主题（内置名 / 捆绑 snowwhite / 用户 TOML；默认 gruvbox-dark）
  :tutor [模块|reset <模块>]
                  导师模式（交互教程+自验，13 模块 100 项覆盖全部键位/命令；
                  透明放行边学边练：Ctrl+Y 掌握 Ctrl+N 记错题本 Ctrl+Q 退出；
                  进度存数据目录 tutor_progress.toml；无参列出模块）

== 远端（SFTP） ==
  :remote <名>    进入远端（~/.ssh/config 别名 + remotes.toml 覆盖）
  :remote         列出全部远端；远端内 dd/yy/p/P/:mkdir/:find/:grep 同本地
  首连指纹确认    strict_host_key = ask|accept|no（缺省 ask：y 接受写入
                  known_hosts / n 拒绝中止；no 等效 known_hosts = false）
  连接增强        ProxyJump（ssh config 透传）/ ssh-agent 认证（SSH_AUTH_SOCK，
                  unix）/ keepalive 30s

== 鼠标 ==
  左键单击        切换焦点至点击 pane 并聚焦条目（已聚焦再击 = 打开；
                  双击 = 直接打开；右栏打开 = 进入目录）
  左键 ".." 行    聚焦/返回上级
  右键条目        上下文菜单（Open/Info/Copy/Move/Rename/Delete；左栏）
  滚轮            逐行滚动焦点 pane 列表

== 历史 ==
  :histprev       目录历史后退（当前 tab 独立）
  :histnext       目录历史前进
  :history / :his 目录历史菜单（j/k 移动，Enter/l 导航，dd 移除）

  推荐键位映射（config.toml 的 [normal] 段，注意 Ctrl-I 与 Tab 同键码、
  rvifm 已把 Tab 用于 pane 焦点切换，故不设默认键）：
    [normal]
    prepend_keymap = [
      { on = ["C-o"], run = "histprev" },
      { on = ["C-i"], run = "histnext" },
    ]

== 其他 ==
  :q / :quit      退出
  :help           本帮助页
  Esc             关闭当前覆盖层/退出可视选择
  ↑/↓（命令行内） 浏览已执行命令（frecency 排序跨会话持久，常用优先；
                  本会话未入库命令并入；Enter 执行，Esc 取消）
  Tab（命令行内） 补全当前词为条目名（前缀匹配循环；~ 展开 HOME）
  :frecency stats 导出/管理 frecency 数据库（export <file> JSON；
                  purge confirm 全清；prune --before <日期> 按时间裁剪）
  :cmdmark <tag>  命令书签（写入 frecency cmd topic；命令行内 ' 展开标签）
  gi              打开 git TUI（PATH 探测：gitui → ziggity → lazygit；:gitui 同）

提示：用户配置见 README（config.toml：[normal] 键位分层 / [opener]+[open] / [ui] theme / [frecency] / [keymap]）。
本帮助页按 q 或 Esc 返回列表，光标与滚动位置保持不变。
键位分层扩展（M33）：config.toml 除 [normal] 外支持 [visual]/[view] 三层
（prepend/append/replace）——进入对应模式（v/w）时用户绑定生效，退出还原。
未配置模式行为不变。
