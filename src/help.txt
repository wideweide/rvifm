rvifm 帮助（vim 风格文件管理器）
参考 vifm 交互范式，非 fork、非行为级兼容。

== 导航 ==
  j / k           光标下移/上移（首尾环绕；首行 k 上到 ".." 行）
  l / Enter       进入目录/归档；普通文件用系统默认程序打开
  h               返回上级目录（归档根返回归档所在物理目录）
  gg              跳到列表顶部（".." 行）
  G               跳到列表末项
  Ctrl-u / Ctrl-d 半页上翻/下翻
  ..              列表顶部固定条目：l/Enter 返回上级；根目录隐藏

== 搜索与过滤 ==
  /{词}           搜索（实时跳转 + 匹配子串高亮 + 状态栏计数 i/N）
  n / N           下一个/上一个匹配
  ={glob}         过滤（如 =*.txt；Esc 清除）
  f / F {字符}    按文件名首字符快速定位（; 同向重复，, 反向）
  o               跳转选择器（frecency 合一视角）
  :j / :J         仅目录 / 仅文件的跳转选择器
  :recent         近期视角（全部条目按最后访问时间倒序，含会话内跳转）
  '{字符}         keyword 直达（如 'd 跳到 keyword=d 的最高排名目录；
                  :keyword <chars> 设置书签，config.toml [quickjump] 可配别名）

== 选择、标记与批量 ==
  v               可视选择（j/k 扩选，Esc 退出）
  t               标记/取消标记当前条目（tag）
  :select {glob}  按 pattern 批量标记（无参=当前条目）
  :unselect       同上取消（无参=清空全部）
  :tag copy|move|delete <目录>   对标记集合执行批量操作（复制/移动后台执行）

== 文件操作 ==
  yy              复制到 yank 缓冲区（可视选择/标记优先，count 前缀支持 Nyy）
  p / P           粘贴：p=复制到当前目录，P=移动到当前目录
  dd              删除（应用内暂存，u 可恢复）
  DD              永久删除（不可恢复，强提示）
  u               撤销上一次操作（逆序，跨 tab）
  cw              批量重命名（$EDITOR 编辑名单）
  :rename 新名    重命名当前条目
  :copy / :move <目录>
  :mkdir / :touch <名>   （:mkdir 后光标定位新目录）
  :mk <名>        创建并进入新目录
  :cd <目录>
  :file           显示当前条目详情（路径/大小/权限/修改时间/类型）
  :keyword <chars>  设置当前目录书签 keyword（`-` 清除；' 直达的锚点）

== 多标签 ==
  :tabnew / :tabclose
  gt / gT / {N}gt 切换标签
  :tabmove {N}    调整标签顺序

== 视图 ==
  Tab             切换左右 pane 焦点（双栏均可导航）
  w               右 pane 在目录列表与预览间切换
  :tree           树视图（只读，depth 可选；再执行恢复平铺）
  :compare        左右 pane 目录对比（= 同 / ! 异 / < 仅左 / > 仅右；只读）
  :view           同 w
  Ctrl-G          文件详情对话框
  :jobs           后台作业列表（j/k 选择、x 取消、Esc 关闭）
  :trash          暂存区菜单（恢复误删文件）

== 鼠标 ==
  左键单击        聚焦条目（已聚焦再击 = 打开；双击 = 直接打开）
  左键 ".." 行    聚焦/返回上级
  右键条目        上下文菜单（Open/Info/Copy/Move/Rename/Delete）
  滚轮            逐行滚动列表

== 历史 ==
  :histprev       目录历史后退（当前 tab 独立）
  :histnext       目录历史前进
  :history        目录历史菜单（j/k 移动，Enter/l 导航，dd 移除）

  推荐键位映射（keymap.toml，注意 Ctrl-I 与 Tab 同键码、
  rvifm 已把 Tab 用于 pane 焦点切换，故不设默认键）：
    [normal]
    prepend_keymap = [
      { on = ["C-o"], run = "histprev" },
      { on = ["C-i"], run = "histnext" },
    ]

== 其他 ==
  :q              退出
  :help           本帮助页
  Esc             关闭当前覆盖层/退出可视选择
  ↑/↓（命令行内） 浏览本会话已执行的命令（Enter 执行，Esc 取消；上限 100）
  Tab（命令行内） 补全当前词为条目名（前缀匹配循环；~ 展开 HOME）

提示：用户配置见 README（TOML：keymap/opener/主题分层）。
本帮助页按 q 或 Esc 返回列表，光标与滚动位置保持不变。
