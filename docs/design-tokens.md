# design-tokens — 视觉语义定稿（M95-2）

> 本文件是 rvifm 视觉决策的唯一事实来源；后续只做参数化调整，不再反复改语义。

| 语义 | 规则 |
|---|---|
| 焦点标签 | 白底 + 反色文字（opaline 主题选中样式） |
| 非焦点标签 | 白字、无背景 |
|  pane 标题栏 | 焦点侧选中样式，失焦侧 TopLine；预览获焦时目录栏标题按失焦 |
| 预览/`:diff` 边框 | 同一套 pane_border_style；焦点强调、失焦灰 |
| 预览框 | 标题栏 + 下方完整方框（非 U 型） |
| 可视选择 / t 标记 | 同一背景样式（selected_row_style），状态栏 `N tagged` 区分来源 |
| 查询命中 | 黄底黑字叠加在语法高亮之上（不关闭语法） |
| 增删行底色 | 深绿 / 深红，词级差异用亮绿/亮红底 |

主题来源：`opaline`；文件类型图标 `devicons`；终端无 Nerd Font 时降级纯文本。
